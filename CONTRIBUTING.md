# Contribuire

- Aprire una issue per anomalie, richieste di riproducibilità o migliorie.
- Preservare i sorgenti originali in `controllers/` e `scripts/bitrate_var_original.sh`; sviluppare eventuali correzioni in file separati con changelog.
- Per ogni modifica alla logica di mitigazione: documentare topologia, bitrate, durata, versione dipendenze e output misurato.
- Non caricare catture o log con indirizzi/dati di reti reali.
- Coordinare contributi e licenza con entrambi gli autori.
